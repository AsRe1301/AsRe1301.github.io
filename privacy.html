2. About the app

AsRe Uploader (“the app”) is a private, non-commercial tool that runs locally on the operator’s own computer. Its only purpose is to upload videos and their metadata (title, description, tags, category, privacy status) to the operator’s own YouTube channel via the YouTube Data API v3. The app is not offered to third parties and has no other users.

3. Google user data accessed

The app requests a single OAuth 2.0 scope:

https://www.googleapis.com/auth/youtube.upload

With this permission the app can only upload videos to the connected channel. It does not access, read or store any other Google or YouTube account data – for example e-mail address, contacts, comments, playlists, subscribers or analytics.

Data processed by the app:

  • OAuth tokens (access token and refresh token) issued by Google after the operator grants consent.
  • Video files and metadata that the operator selects locally and that are sent to YouTube during the upload.
  • API responses from YouTube (e.g. the ID of the uploaded video), used only to confirm a successful upload.

4. How the data is used

The data is used exclusively to perform uploads to the operator’s own YouTube channel. It is not used for any other purpose.

5. Storage and security

  • OAuth tokens are stored only locally in a file on the operator’s computer. They are never uploaded to any server, repository or cloud service operated by the developer.
  • The app has no backend server and no database. Network communication takes place only between the local computer and Google’s OAuth and YouTube API endpoints, encrypted via HTTPS.
  • The OAuth client secret and token files are excluded from version control and are protected by the security measures of the operator’s computer.

6. Sharing and disclosure

Google user data is not sold, rented, shared or transferred to any third party. It is not used for advertising, profiling, or to develop, improve or train generalized or non-personalized AI/ML models. No one other than the operator, as the account owner, has access to the data.

7. Limited Use disclosure

AsRe Uploader’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

8. YouTube API Services

The app uses YouTube API Services. By using the app you agree to the YouTube Terms of Service. Google’s processing of data is governed by the Google Privacy Policy.

9. Retention and deletion

  • Tokens are kept locally until the operator deletes the token file or revokes access.
  • Access can be revoked at any time at myaccount.google.com/permissions (Google Account → Security → Third-party apps with account access). After revocation the stored tokens become invalid and are deleted locally.
  • Uploaded videos are stored by YouTube and can be managed or deleted in YouTube Studio.
  • To request deletion of any data, contact reneascher1301@gmail.com.

10. This website

This website is a static site hosted on GitHub Pages (GitHub Inc., USA). It uses no cookies, no analytics and no tracking. When you visit it, GitHub may process technical data such as your IP address in server logs for security and operational purposes; see the GitHub Privacy Statement. Your language choice (EN/DE) is stored only in your browser’s local storage.

11. Your rights

Under the GDPR you have the right to access, rectification, erasure, restriction of processing, data portability and objection. You may also lodge a complaint with the Austrian Data Protection Authority (Datenschutzbehörde, dsb.gv.at).

2. Über die App

AsRe Uploader („die App“) ist ein privates, nicht-kommerzielles Tool, das lokal auf dem Computer des Betreibers läuft. Einziger Zweck ist das Hochladen von Videos und deren Metadaten (Titel, Beschreibung, Tags, Kategorie, Sichtbarkeit) auf den eigenen YouTube-Kanal des Betreibers über die YouTube Data API v3. Die App wird Dritten nicht angeboten und hat keine weiteren Nutzer:innen.

3. Verwendete Google-Nutzerdaten

Die App fordert einen einzigen OAuth-2.0-Scope an:

https://www.googleapis.com/auth/youtube.upload

Mit dieser Berechtigung kann die App ausschließlich Videos auf den verbundenen Kanal hochladen. Sie greift auf keine anderen Daten des Google- oder YouTube-Kontos zu – etwa E-Mail-Adresse, Kontakte, Kommentare, Playlists, Abonnent:innen oder Analytics – und speichert diese auch nicht.

Von der App verarbeitete Daten:

  • OAuth-Tokens (Access-Token und Refresh-Token), die Google nach der Zustimmung des Betreibers ausstellt.

  • API-Antworten von YouTube (z. B. die ID des hochgeladenen Videos), die nur zur Bestätigung eines erfolgreichen Uploads dienen.

4. Zweck der Verarbeitung

Die Daten werden ausschließlich für Uploads auf den eigenen YouTube-Kanal des Betreibers verwendet und zu keinem anderen Zweck.
